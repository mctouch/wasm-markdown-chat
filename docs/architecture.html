WASM WebGPU Markdown Chat Architecture

AI Avatar Chat with Rust/WASM Frontend + vLLM Backend + WebGPU/WebGL2 Rendering

Frontend Stack

  • • Rust compiled to WASM (wasm-bindgen)
  • • WebGPU with WebGL2 fallback for Safari
  • • Real-time morph target deformation (52 blendshapes)
  • • PBR lighting with rim light

Dual Browser Support

  • • Chrome: WebGPU + Piper TTS
  • • Safari: WebGL2 + Web Speech API
  • • CDP debugging (Chrome) + safaridriver (Safari)
  • • SSH tunnel for remote debugging
